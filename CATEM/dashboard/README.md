# CATEM Dashboard

The live Streamlit dashboard is implemented at:

```text
dashboards/streamlit_dashboard.py
```

Dashboard pages planned for the research prototype:

- Overview
- CATEM Score
- Layer Analysis
- Embodiment
- Presence
- Performance
- Physiology
- Workload
- System
- Correlation Heatmaps
- Validation
- Model Comparison

Run from the repository root:

```bash
streamlit run dashboards/streamlit_dashboard.py
```

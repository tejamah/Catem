# Dataset Download Manifest

This file tracks source datasets for CATEM Benchmark Dataset v1.

## PhysioNet / WESAD

Purpose:

- Physiology
- HR, HRV, ECG, EDA/GSR, skin temperature, stress labels

Source:

- WESAD dataset page: https://ubi29.informatik.uni-siegen.de/usi/data_wesad.html

Target folder:

```text
CATEM/datasets/physionet/
```

## NASA-TLX

Purpose:

- Workload
- Mental demand, effort, frustration, total workload

Target folder:

```text
CATEM/datasets/nasa_tlx/
```

## RoboTurk

Purpose:

- Teleoperation manipulation data
- Robot task performance and video-prediction metrics

Source:

- RoboTurk real robot dataset: https://roboturk.stanford.edu/dataset_real.html

Target folder:

```text
CATEM/datasets/roboturk/
```

## ROS Datasets

Purpose:

- System telemetry
- Navigation, latency, sensor streams, robot logs

Target folder:

```text
CATEM/datasets/rosbags/
```

## CISC-LIVE-LAB-3

Purpose:

- Human-state rich data
- NASA-TLX, SART, SPAM, eye tracking, EEG, watch data, performance

Source:

- Zenodo record: https://zenodo.org/records/10600674

Target folder:

```text
CATEM/datasets/cisc/
```

# CATEM Research Questions

## RQ1

Can CATEM integrate multimodal telepresence metrics across embodiment, presence, physiology, workload, system telemetry, and task performance?

## RQ2

Can CATEM predict overall telepresence quality from multimodal benchmark data?

## RQ3

Does CATEM outperform single-layer models such as presence-only, workload-only, performance-only, and system-only baselines?

## RQ4

Which CATEM layers and features contribute most to telepresence outcomes?

## Validation Target

The benchmark target variable is `telepresence_quality`.

This target is required so CATEM can be tested as a predictive framework instead of only presented as a conceptual score.
